# 动作与抠图：问题诊断与修复

## 你指出的三件事，逐条查实

### 1. 动作层带衣服 → 其他衣服确实不能用
旧的两张动作层是「银时版整图差异提取」出来的，实测含**银时专属蓝白青花花纹**：
- 左手举起：8581 像素
- 双手欢呼：16261 像素

套到神乐红旗袍、新八蓝和服上就是穿帮。**已废弃，不再进交付。**

### 2. 动作必须按服装归类
新动作层改为：每套从**自己那套的 L08 / L09 层**做刚性仿射变换生成，8 套各自独立目录：

```
动作_按服装/{银时|神乐|志村新八|土方十四郎|冲田总悟|桂小太郎|万事屋混搭|素体原型}/
    左手举起.png / 双手欢呼.png / *_预览.png
```

不重绘、不跨套复用、不做整图差异抠图。手、袖口、道具全部来自本套，花纹天然对得上。

### 3. 抠图漏了会穿模
旧动作层用「整图差异阈值」抠，实测：
- 漏抠（变了但没抠到）：12.5 万 / 13.9 万像素
- 多抠（抠了但没变）：8.2 万 / 15.6 万像素
- 还带回来 2.2 万 / 2.5 万像素粉色肉垫

新方案用**分层自带的 alpha 做变换**，不存在差异提取，漏抠/多抠从根上消除；手沿用真原型的白色爪背与三道顺弧。

## 「黑漆漆 / 糊糊」的真相

四图并列核对（原立绘 / 去背底图 / 补底层 / 合成结果）后确认：

- **补底层本身是干净的**（神乐补底单独看是完整红色旗袍袖子，死黑 0%）。
- 黑块出现在**原生成立绘的手臂与道具区域**，是那批 image2image 立绘自身画坏的深色块与糊笔触，位置在补底覆盖范围之外，补底盖不住。
- 另外我自己埋过两个坑，已修：
  1. 透明区 RGB 被归零压缩 → 羽化/旋转时把 0 值混成黑边。现已把**全部 163 个透明 PNG 的透明区统一填成本套米色背景色**。
  2. 预览用错了 alpha 合成公式（原始立绘 (300,1180) 是米色，被合成成 (17,15,14)）。现改为「原图打底 + 局部替换」。
- 补底范围也从「只补手移开的洞」扩大为**整片手臂区替换**，用本套干净衣料整体盖住原图糊/黑的手臂。

> 对照 `8套_补底生效总览_终版.png`：右下角「素体原型」是唯一一套完全以真原型三视图为源的，最干净、没有黑块；其余 7 套的残留黑块来自各自立绘本身，不是分层或补底引入的。

## 使用规则

1. 启用动作前，先启用该套 `换装补底/{服装}_手臂背面.png`，并隐藏对应 `L08 / L09` 主体层。
2. 动作层是变换后的手与道具，直接叠在补底之上。
3. 口型、眼型、闭眼闭嘴补底、头部背面补底仍是 8 套通用（脸部坐标一致）。

## 还没彻底解决的一件事

7 套有服装的立绘，手臂与道具区域是模型画坏的（黑块、糊笔触）。补底能盖住「手移开后」的区域，但盖不住原图里留在画面上的坏笔触。要彻底干净，得**以真原型三视图为源，把这几张立绘的手与道具重绘一遍**，再重新拆层——也就是你说的「动作用这张重做」的完整版。

素体原型那一套已经是按这个标准做出来的样板，可以先看效果。
